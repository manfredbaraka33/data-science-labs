# Data science labs — Manfred Baraka

Health data analysis in Python, from statistics to machine learning.
Each lab answers a real health question with real data.

## Labs

| Lab | Question | Methods | Key result |
|-----|----------|---------|------------|
| [01](labs/01-heart-stats/) | Heart rate and sex vs heart disease | t-test, chi-square | Disease: 19 bpm lower heart rate; 2x more common in men |

## Tools

Python, pandas, SciPy, Jupyter

## How to run

    pip install -r requirements.txt

Then open any lab's `analysis.ipynb` and click **Run All**.
